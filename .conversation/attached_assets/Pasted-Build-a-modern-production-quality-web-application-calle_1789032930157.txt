Build a modern, production-quality web application called **VirtualLab** for our Smart India Hackathon 2026 project under Problem Statement **SIH26207 (Smart Education)**.

### PROJECT PURPOSE

VirtualLab is an intelligent virtual laboratory platform specifically designed for **Computer Science and Information Technology students**.

The platform should go beyond being a normal online code editor or compiler.

Its core purpose is to help students understand how programs execute internally by providing:

* Interactive programming practicals
* Step-by-step program execution
* Data structure visualization
* Memory and pointer visualization
* Debugging and fault-diagnosis challenges
* AI-assisted viva assessment
* Faculty monitoring and assessment

The first flagship laboratory will focus on **C++ Data Structures**, beginning with **Linked Lists**.

IMPORTANT:
Do NOT attempt to implement the complete virtual laboratory yet.
For this first development phase, build the application's foundation, navigation, authentication UI, dashboards, and overall visual system. The actual code execution engine and memory visualization will be implemented in later phases.

# DESIGN SYSTEM

Create a professional educational technology / developer-tool interface.

The application should feel like a combination of:

* Modern coding IDE
* University laboratory platform
* Interactive learning system

Avoid making it look like a generic school LMS.

Design principles:

* Clean
* Technical
* Modern
* Professional
* Minimal unnecessary decoration
* Excellent spacing
* Strong typography
* Responsive
* Accessible
* Desktop-first but mobile-friendly

Use a neutral/slate interface with a restrained indigo/blue accent.

Use cards, subtle borders, rounded corners, and clean data visualization placeholders.

Do NOT overuse gradients, glassmorphism, excessive animations, or huge hero sections.
